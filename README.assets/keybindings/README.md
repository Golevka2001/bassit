# Assets For Keybindings

The [keyboard layout figure](./apple-wireless-keyboard.png) is generated using [keyboard-layout-editor.com](https://www.keyboard-layout-editor.com/). And [apple-wireless-keyboard.json](./apple-wireless-keyboard.json) is the JSON file for this keyboard layout.

The [keybindings figure](./keybindings.drawio.png) is drawn using [draw.io](https://app.diagrams.net/) based on the keyboard layout figure. And [keybindings.drawio](./keybindings.drawio) is the Draw.io file for this figure.
